# Surrogate Modeling Learning

Hands-on learning repo for surrogate modeling + DOE for expensive simulations.

- Surrogates: response surface, Gaussian process (Kriging)
- Validation: error metrics, cross-validation, diagnostic plots

## How to run
1. Create env and install deps
   pip install -r requirements.txt
2. Launch notebooks
   jupyter notebook
